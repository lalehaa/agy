Antigravity Developer Cheat Sheet

                
Quick reference for commands, keybindings, files, and architecture rules.

            


            

                
                

                    

                        
                        Slash Commands
                    

                    

                        
/grill-me - Interview agent to walk down design tree before code

                        
/goal - Instruct agent to run relentlessly until goal completion

                        
/schedule - Set up cron tasks or background timers

                        
/learn - Persist user corrections and workspace patterns

                    

                


                
                

                    

                        
                        Subagent Orchestration
                    

                    

                        
invoke_subagent - Spawn parallel subagents with roles

                        
send_message - Peer messaging via subagent conversation ID

                        
manage_subagents - List active subagents or terminate trees

                    

                


                
                

                    

                        
                        Workspace Architecture Rules
                    

                    
    
                        
  • New apps belong in dedicated root subfolders inside workspace.
    • 
                        
  • Technical specs and docs reside inside the app folder.
    • 
                        
  • Virtual environments (`.venv`) belong in the app subfolder.
    • 
                        
  • Prefix commands with `source .venv/bin/activate && ...`.
    • 
                    

                


                
                

                    

                        
                        Terminal Sandbox Policy
                    

                    
    
                        
  • Standard mode (`BypassSandbox: false`): Isolated, safe auto-runs.
    • 
                        
  • Bypass mode (`BypassSandbox: true`): Host/network access.
    • 
                        
  • Minimize unsandboxed steps; isolate single commands needing bypass.
    •
