# Antigravity Catalog

This directory houses reference catalogs for Google Antigravity (AGY) tools, workflows, commands, and configurations.

## Contents

- **[slash_commands.md](slash_commands.md)**: Comprehensive human-readable guide detailing all 25 helpful slash commands categorized across autonomous workflows, session & trajectory management, model reasoning, customizations, permissions, and tool integrations. Includes descriptions, syntax, options, and real-world combo recipes.
- **[plan_vs_goal.md](plan_vs_goal.md)**: Detailed breakdown comparing `/plan` (architectural blueprint & human-in-the-loop sign-off) vs `/goal` (autonomous execution & relentless verification), featuring workflow diagrams and combination patterns.
- **[slash_commands.json](slash_commands.json)**: Machine-readable JSON catalog schema containing all command definitions, categories, aliases, syntax patterns, descriptions, and examples for programmatic ingestion.
